# 土木工程毕业设计 CAD 改图 Skill

一个面向中国土木工程毕业设计的 CAD 改图流程：查相似案例和规范 → 给出改前／改后对照和逐项依据 → 等待整版确认 → 正式出图与复核。

## 使用

将本仓库的 SKILL.md 放入 Codex 的个人 skills 目录下名为 civil-engineering-cad-revision-skill 的文件夹。调用示例：

> 使用 $civil-engineering-cad-revision-skill，检查这张住宅标准层平面图的入户门调整方案。先给我改前改后对照、修改编号和规范依据，不要先改正式 CAD。

本仓库不包含毕业设计图纸、CAD 软件或自动化脚本。实际读图、导出和渲染取决于可用工具。毕业设计成果不是施工图审查或专业安全签认。
